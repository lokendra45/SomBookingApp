# SOM Booking App

A native Android app I built for the SOM junior developer assignment. It covers the full customer booking flow from browsing services to confirming a booking.

## What it does

- Browse and search services
- View service details and pick a date/time slot
- Fill in my name and contact, then confirm the booking
- View my past bookings

## Tech

- Kotlin + Jetpack Compose
- ViewModel + StateFlow
- Kotlin Coroutines
- Mock API (in-memory, simulates a real backend)
- MVVM + Repository pattern
